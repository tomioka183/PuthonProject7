# Проект "Магазин: Категории и Товары"

## Описание
Этот проект реализует базовую структуру для управления категориями товаров и самими товарами,
включая подсчет общего количества категорий и товаров с использованием объектно-ориентированного подхода.
## Функционал
- **Классы Product и Category:** Определены классы для представления товаров и их категорий.
- **Атрибуты классов:** Для Category реализованы атрибуты `category_count` и `product_count`
  для отслеживания общего количества категорий и товаров.
- **Тестирование:** Проект включает модульные тесты для проверки корректности
  инициализации объектов и работы счетчиков.
## Использование
Для запуска тестов используйте команду:
`poetry run pytest`

Для проверки покрытия тестами:
`poetry run pytest --cov=src`

Для форматирования кода:
`poetry run black src/`
`poetry run isort src/`

Для проверки кода линтером:
`poetry run flake8 src/`
